## Concrete open findings

1. **Electron patch maintenance:** [44.4.5](https://releases.electronjs.org/release/v44.4.5) is the current stable release observed at review, with further native backports; this app uses 44.4.2. An unchanged Chromium version number across patches does not mean identical fixes. Review those changes, update the archive digest and dependency together in a new artifact version, and run compatibility/installer/upgrade/security checks. No claim is made that every backport is exploitable in this calendar.
2. **Seven fuse targets remain unmet:** run-as-Node, Node environment options, CLI inspection and additional file-protocol privileges are enabled; cookie encryption, embedded ASAR integrity and ASAR-only loading are disabled. Cookie encryption is defense in depth; the app does not keep browser authentication credentials. Renderer isolation and packaged DevTools settings do not flip executable fuses. Establish a reviewed policy and test workers/import, Google loopback, tray/startup, encrypted sessions and recovery. ASAR integrity needs a correct embedded header hash and tampered-copy refusal check; see [Electron's integrity instructions](https://www.electronjs.org/docs/latest/tutorial/asar-integrity). Disabling CLI inspection requires an acceptance path independent of Playwright's current main-process inspector. Do not silently ship an inspection-enabled exception as production hardening.
3. **Chromium notices omitted during installation:** the package contains `LICENSES.chromium.html` (20,472,830 bytes; SHA-256 `7b328b8c7463ac9bfc7dc648c751533517c8441a0b5b21047d6c0b2620e60d70`); the installed folder lacks it. Electron's license and archived better-sqlite3/node-addon-api licenses are present. The inspected electron-winstaller 5.4.4 `template.nuspectemplate` explicitly lists root extensions and omits HTML; its `additionalFiles` option provides a repair path. A new installer must retain the exact notice file and verify its installed hash. Complete bundled JavaScript notices and redistribution obligations still need review.
4. **Native provenance remains partial:** the extractor's [versioned manifest](https://github.com/electron/extract-zip/blob/v1.0.5/Cargo.toml) selects ZIP Store/Deflate and zlib-ng. Its lockfile has 52 packages including its own crate. An exact-version [OSV](https://osv.dev/) batch query of all 51 registry packages returns no matching advisories at this checkpoint. ZIP 8.6.0 is outside the affected range of [RUSTSEC-2025-0168](https://rustsec.org/advisories/RUSTSEC-2025-0168.html). The build-only extractor is absent from the installed app. This does not inventory embedded C sources or prove reproducible binaries. SQLite's local amalgamation SHA3-256 is `52fde3de869fc0bff701d7bdc6589e7337f77ebf28303abcfc1e531205895193`, different from the upstream generic amalgamation. The dependency's [generation script](https://github.com/WiseLibs/better-sqlite3/blob/v13.0.3/deps/download.sh) creates custom output and applies patches. Matching version/source ID must not be presented as byte-for-byte upstream equivalence; reconcile generated-source/build provenance before closing this item.
