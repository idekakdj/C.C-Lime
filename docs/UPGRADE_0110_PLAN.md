## Compatibility and recovery

All computers sharing this account need 0.1.10 before profile records are used. Schema 2 prevents an older local client from writing a profile-aware database. Full backups containing profile/history use format 2; older format-1 backups remain readable. A same-account merge can recover profile/history when missing or identical. Copying calendar items deliberately excludes the saved profile and completion ledger. A rollback requires deliberate recovery from the private pre-upgrade copy, not simply opening the new database in an older app.
